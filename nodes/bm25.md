# BM25

## Summary

**BM25** is a lexical ranking function that scores how strongly a document matches query terms, giving more weight to rare terms, diminishing returns to repeated occurrences, and a correction for document length.

## Grounded explanation

For query term $q$ and document $d$, a common BM25 contribution is

$$\operatorname{IDF}(q)\frac{f(q,d)(k_1+1)}{f(q,d)+k_1(1-b+b|d|/L)}.$$

Here $f(q,d)$ is the term frequency from the [[inverted-index]], $|d|$ is document length, $L$ is average length, $k_1>0$ controls frequency saturation, and $0\le b\le1$ controls length normalization. IDF is larger when few documents contain $q$; it can be derived from the [[probability]] that a random document contains the term.

### Worked example

Let $k_1=1.2$, $b=0.75$, $|d|=L$, $f(q,d)=2$, and $\operatorname{IDF}(q)=1.5$. The denominator is $2+1.2=3.2$, so the term contributes

$$1.5\times\frac{2\times2.2}{3.2}=2.0625.$$

If frequency rises from 2 to 20, the contribution does not grow tenfold: it approaches the finite limit $1.5(k_1+1)=3.3$. This saturation prevents repeated keyword stuffing from dominating. A longer-than-average document gets a larger denominator because it has more chances to contain a term by accident.

BM25 compares exact normalized terms; it does not infer that two different words have similar meaning. Its strength is precise lexical evidence, especially identifiers and rare names.
