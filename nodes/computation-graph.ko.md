# 계산 그래프 (Computation Graph)

## 요약

**계산 그래프(computation graph)**는 계산을 연산 노드와 그 사이를 잇는 값으로
표현한다. 간선은 “이 출력이 저 연산의 입력이다”라는 뜻이므로, 그래프는 계산 내용과
의존 순서를 함께 기록한다.

## 상세 설명

[[graph]]에서 시작하자. 정점은 대상이고 방향이 있는 간선은 어느 대상이 다음 대상에
입력을 제공하는지 나타낸다. 계산 그래프에서 각 정점은 연산을 호출하고, 간선은 이름이
붙은 [[tensor]] 값을 전달한다. 그래프 입력은 값을 만드는 정점 없이 들어오며, 그래프
출력은 마지막 소비자를 지난 뒤 나간다.

방향은 실행 규칙을 만든다. 한 연산은 필요한 입력값이 모두 생긴 뒤에만 실행할 수 있다.
노드 `A`가 `h`를 만들고 노드 `B`가 `h`를 사용한다면 `A`가 `B`보다 먼저 실행되어야
한다. 의존 순환이 없는 그래프는 모든 생산자가 소비자보다 앞에 오도록 정렬할 수 있다.
이 순서는 병렬성도 드러낸다. 입력이 준비되었고 서로 의존하지 않는 두 노드는 함께
실행할 수 있다.

**구체적인 예.** 입력 텐서 `x = [2, 3]`을 사용하자. `Multiply` 노드는 `x`와 상수
텐서 `[4, 5]`를 받아 이름이 `p`인 값 `[8, 15]`를 만든다. `Add` 노드는 `p`와
`[1, -3]`을 받아 출력 `y = [9, 12]`를 만든다. 의존 그래프는
`x → Multiply → p → Add → y`이다. `p`가 아직 없으므로 `Add`를 먼저 실행할 수 없다.
연결값에 이름을 붙이면 이 제약이 명시적이고 이식 가능한 형태가 된다.
