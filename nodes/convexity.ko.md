# 볼록성

## 요약

함수는 그 그래프가 그릇처럼 위로 휘어질 때 **볼록(convex)**하다: 그래프 위 두 점을 잇는 직선은 항상 그래프 위 또는 위쪽에 머무르고, 함수는 결코 자신의 어떤 접선보다도 아래로 내려가지 않으며, 그 기울기는 오직 증가하기만 한다. 유일한 보상은 **옌센 부등식(Jensen's inequality)**이다 — "함수의 평균은 평균의 함수보다 크지 않다."

## 상세 설명

### 함수와 "위"라는 말의 의미

**함수** $f$는 입력 숫자 $x$를 받아 출력 숫자 $f(x)$를 반환한다; 그 **그래프**는 평면 위에 그려진 점들의 집합 $(x, f(x))$로, 입력은 가로축에, 출력은 세로축에 놓인다. 어떤 곡선이 다른 곡선보다 "위"에 있다는 말은: 같은 가로 위치 $x$에서 그 세로($f(x)$) 값이 더 크다는 뜻이다.

### 관점 (a): 현이 그래프 위 또는 위쪽에 놓인다

$a < b$인 두 입력 $a$와 $b$를 고른다. **현(chord)**은 그래프 위 두 점 $(a, f(a))$와 $(b, f(b))$를 잇는 직선 선분이다. $a$와 $b$ 사이의 임의의 입력은 두 끝점의 **가중 평균(weighted average)**으로 쓸 수 있다: $0 \le t \le 1$인 가중치 $t$를 골라

$$x = (1-t)\,a + t\,b$$

를 만든다. 여기서 $t$는 점을 $a$($t=0$일 때)에서 $b$($t=1$일 때)로 미끄러뜨린다; 두 가중치 $1-t$와 $t$는 각각 0 이상이고 합이 $1$이므로, $x$는 정말로 $a$와 $b$ 사이에 놓인다. 그 $x$ 위에서 **현**의 높이는 끝점 높이들의 *같은* 가중 평균, 즉 $(1-t)\,f(a) + t\,f(b)$이다(직선은 자신의 끝점을 선형으로 보간한다 — 이는 그저 산술일 뿐이다). 함수 $f$가 **볼록**한 것은 정확히 실제 그래프의 높이가 현의 높이를 결코 초과하지 않을 때다:

$$f\big((1-t)\,a + t\,b\big) \;\le\; (1-t)\,f(a) + t\,f(b)
\qquad\text{모든 } 0 \le t \le 1 \text{에 대해.}$$

이것이 정의다. 그릇 모양은 이를 그림으로 나타낸 것이다: 그릇의 임의의 두 점 사이에 끈을 팽팽히 당기면 그 끈은 그릇의 바닥 위쪽에 매달린다.

### 관점 (b): 함수가 자신의 접선들 위쪽에 놓인다

입력 $x_0$에서의 **접선(tangent line)**은 그래프와 $(x_0, f(x_0))$에서 맞닿으며 그 지점에서 같은 기울기를 갖는 직선이다 — 그리고 그 기울기는 정확히 [[derivative]] $f'(x_0)$, 즉 $x_0$에서 $f$의 순간 변화율이다. 임의의 입력 $x$에서 접선의 높이는

$$\text{tangent}(x) = f(x_0) + f'(x_0)\,(x - x_0)$$

이다. 즉 맞닿는 높이 $f(x_0)$에서 시작해 기울기 $\times$ 가로 이동을 더한다. 볼록 함수의 경우 그래프는 결코 어떤 접선보다도 아래로 내려가지 않는다: 모든 $x$에 대해 $f(x) \ge f(x_0) + f'(x_0)(x - x_0)$. 그릇은 그 옆면에 기대어 놓은 평평한 자보다 항상 위쪽에 있다. 이 관점은 최적화로 이어지는 다리다: 어떤 지점에서 기울기 $f'(x_0) = 0$이라면, 접선은 높이 $f(x_0)$에서 수평이고, 그래프 전체가 그 수평선 위쪽에 놓이므로 $f(x_0)$는 **전역 최솟값(global minimum)**이다 — 볼록 함수의 평평한 지점은 결코 단순한 국소적 함몰일 수 없다.

### 관점 (c): 이계도함수가 음이 아니다 — 그리고 이것이 다른 관점들을 어떻게 하나로 묶는가

[[derivative]] $f'$ 자체도 $x$의 함수다(각 지점에서의 기울기). 그것을 다시 [[derivative]]하면 **이계도함수(second derivative)** $f''$ — *기울기의* 변화율 — 을 얻는다. 이것이 세 관점을 통합하는 정당화 항등식이다:

> $f$가 볼록 $\iff$ 어디서나 $f''(x) \ge 0$.

*이유*는 이렇다: $f'' \ge 0$은 $x$가 오른쪽으로 움직일 때 기울기 $f'$가 **감소하지 않는다(non-decreasing)**는 뜻이다(변화율이 결코 음수가 아닌 양은 결코 줄어들지 않는다). 오직 가팔라지기만 하는 기울기 — 완만하다가 가팔라지는 — 는 정확히 위로 휘어지는 곡선이며, 이는 정확히 관점 (a)의 그릇 모양이자 관점 (b)의 접선-위쪽-놓임 속성이다. 거꾸로 읽으면: 만약 기울기가 어디선가 *줄어든다면*, 곡선은 현 위로 불룩 튀어나올 것이고 현이 그 아래를 자르게 되어 볼록성이 깨질 것이다. 그러므로 "이계 [[derivative]]가 결코 음수가 아니다"와 "위로 휘어진다"는 같은 진술이며, 음이 아닌 곡률이 바로 현 조건과 접선 조건 모두를 강제하는 것이다.

### 보상: 옌센 부등식

관점 (a)는 그래프를 **두** 점 사이의 현과 비교했다. 같은 위로 휘어지는 성질이 **여러** 점을 한꺼번에 평균 낼 수 있게 해 준다. 입력 $x_1, x_2, \dots, x_n$과, 각각 음이 아니고($w_i \ge 0$) 합이 1인($w_1 + w_2 + \cdots + w_n = 1$) **가중치(weight)** $w_1, w_2, \dots, w_n$을 생각하자. 입력들의 **가중 평균**은 $\bar{x} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n$이다. 그러면 임의의 볼록 $f$에 대해:

$$f\!\left(\sum_{i} w_i\, x_i\right) \;\le\; \sum_{i} w_i\, f(x_i)
\qquad\text{(옌센 부등식).}$$

말로 풀면: **$f$의 평균은 평균의 $f$보다 크지 않다.** 관점 (a)의 두 점짜리 현 부등식은 가중치 $1-t$와 $t$를 갖는 $n=2$의 특수한 경우이며; 점을 더 쌓아 나가면(새로 추가되는 점마다 다시 관련 현 위 또는 위쪽에 놓이면서) 이는 임의 개수의 가중치 있는 점들로 확장된다. *(가중치를 확률변수 $X$에 대한 확률 분포로 읽으면, 이는 $f(E[X]) \le E[f(X)]$로 쓰인다 — 같은 진술이며, 브레인의 다른 곳에서도 쓰인다.)*

### 오목: 거울상

함수는 *반대* 방향으로 휘어질 때 — 그릇 대신 돔 모양일 때 — **오목(concave)**하다. 모든 것이 뒤집힌다: $f'' \le 0$(기울기가 감소하지 않는 대신 증가하지 않는다), 그래프는 자신의 현과 접선 위 또는 *아래*에 놓이고, 옌센은

$$f(\sum_i w_i x_i) \ge \sum_i w_i f(x_i)$$

로 뒤집힌다. 직선, 즉 $f'' = 0$은 경계에 해당하는 경우다: 그것은 볼록이면서 동시에 오목이며, 옌센은 **등호**로 성립한다.

### 작동 예시

$f(x) = x^2$를 보자. 그 [[derivative]]는 $f'(x) = 2x$(기울기)이고, 그것의 [[derivative]]는 $f''(x) = 2$이다. 어디서나 $2 \ge 0$이므로 $f$는 **볼록**이다 — 그것도 강볼록(strictly convex)인데, 곡률이 정말로 양수이지 0이 아니기 때문이다. 이제 두 점 $x_1 = 1$과 $x_2 = 3$, 동일한 가중치 $w_1 = w_2 = \tfrac{1}{2}$(음이 아니고 합이 $1$)로 옌센을 확인해 보자.

- **좌변 — 평균의 $f$.** 가중 평균은 $\bar{x} = \tfrac{1}{2}\cdot 1 + \tfrac{1}{2}\cdot 3 = 2$이므로 $f(\bar{x}) = 2^2 = 4$이다.
- **우변 — $f$의 평균.** $f(1) = 1$이고 $f(3) = 9$이므로, 평균은 $\tfrac{1}{2}\cdot 1 + \tfrac{1}{2}\cdot 9 = \tfrac{1 + 9}{2} = 5$이다.

옌센은 $4 \le 5$를 예측한다 — 참이며, 점들이 서로 다를 때 강볼록 함수가 요구하는 대로 **엄격한** 부등식($4 < 5$)이다. $1$의 차이는 포물선의 위로 볼록한 불룩함이 $x = 2$에서 곡선을 현보다 아래로 끌어당긴 결과다.

대조를 위해 **선형** 함수 $f(x) = 2x + 1$(따라서 $f'' = 0$, 경계에 해당하는 경우)을 보자. 같은 $x_1 = 1$, $x_2 = 3$, 동일한 가중치로: 평균 입력은 $2$이고 $f(2) = 5$이다; 입력들은 $f(1) = 3$과 $f(3) = 7$을 주며, 평균은 $\tfrac{3 + 7}{2} = 5$이다. 양변이 모두 $5$로 같으므로 옌센은 **등호**로 성립한다 — 간극을 만들 곡률이 없을 때 예상되는 그대로다. (이계도함수 $f'' < 0$을 갖는 $f(x) = \sqrt{x}$ 같은 오목 함수의 예라면, 대신 평균의 $f$가 $f$의 평균을 *초과*하게 되어 부등식이 뒤집힐 것이다.)
