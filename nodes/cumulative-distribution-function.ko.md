# 누적분포함수

## 요약

[[probability-distribution]]은 [[random-variable]]의 확률이 그 값들에 걸쳐 어떻게 퍼져 있는지 말해준다 — 값이 서로 떨어져 있으면 점질량(pmf)으로, 값이 연속적인 범위를 이루면 높이 곡선 아래의 면적(pdf)으로. **누적분포함수**(cumulative distribution function, CDF), 기호 $F$는 같은 정보를 *누적 합계*로 다시 포장한다: $F(x)$는 변수가 $x$ 이하로 나올 확률, 즉 $F(x) = P(X \le x)$이다. 이는 분포를 맨 왼쪽부터 $x$까지 누적함으로써 만든다 — 이산의 경우 $x$ 이하인 모든 점의 질량을 더하고, 연속의 경우 $x$까지 곡선 아래의 면적을 쓸어 담는다. 이 하나의 함수는 두 종류의 변수 모두에 대해 작동하며, 전체 확률이 1이기 때문에 항상 0(맨 왼쪽)에서 1(맨 오른쪽)로 상승하고, 뺄셈으로 임의의 구간의 확률을 읽어낼 수 있게 해준다, $P(a < X \le b) = F(b) - F(a)$. 연속의 경우 누적 합계와 높이 곡선은 서로 역연산이다: 높이는 누적 합계가 커지는 *속도*이므로, CDF를 미분하면 밀도를 되찾는다. CDF는 또한 반대 질문에도 답한다 — "주어진 누적확률에 해당하는 값은 무엇인가?" — 이는 중앙값(누적 합계가 절반에 도달하는 값)과 같은 분위수를 제공한다.

## 상세 설명

### 이 개념이 무엇인가

[[probability-distribution]]에서, [[random-variable]] $X$ — 값이 불확실한 양 — 의 분포는 그 확률이 어디에 사는지에 대한 완전한 규칙이라는 것을 떠올려보자. $P(\text{X에 대한 진술})$을 "그 진술이 참일 확률"로 쓴다. 분포는 두 가지 옷을 입고 나타난다: *이산적인* $X$(분리되어 나열 가능한 값을 취하는)에 대한 **확률질량함수**(pmf) $p$, 여기서 $p(x) = P(X = x)$는 값 $x$에 정확히 놓인 가중치이며; *연속적인* $X$(직선상의 어떤 구간에 걸쳐 모든 값을 취하는)에 대한 **확률밀도함수**(pdf) $f$, 여기서 확률은 구간에 대한 곡선 $f$ *아래 면적*이고 정확히 하나의 점의 확률은 0이다. 두 옷 모두에서 전체 확률은 정확히 1이다, $X$가 반드시 *어떤* 값을 취하기 때문이다.

pmf와 pdf는 *국소적* 확률에 대한 기술이다 — 한 점에 무엇이 놓여 있는지, 또는 한 점 근처에서 확률이 얼마나 촘촘한지. **누적분포함수**(CDF)는 바로 그 동일한 분포를 취해 다른, *누적된* 질문에 답한다:

$$ F(x) = P(X \le x). $$

말로 하면: $F(x)$는 $X$가 값 $x$ *또는 그보다 작은 어떤 값*으로 나올 확률이다. 기호 $F$는 실수 입력 $x$의 함수이며 확률(0과 1 사이의 수)을 반환한다. "$X \le x$"는 "$X$가 수 $x$보다 작거나 같다"는 사건이다. 이 하나의 정의 — $x$까지 모든 것을 누적한다 — 가 개념 전체다. 새로운 확률 조각이 아니라, 기존 분포를 *국소적 가중치*가 아니라 *누적 합계*로 읽은 것이다.

pmf나 pdf가 이미 모든 것을 말해주는데 왜 굳이 필요한가? 세 가지 이점이 CDF를 옳은 도구로 만든다: (1) 이산과 연속 변수(그리고 혼합까지도)를 같은 공식 $P(X \le x)$로 기술하는 **하나의 통일된 대상**이라는 점, 여기서 pmf와 pdf는 두 가지 다른 장치가 필요하다; (2) "구간의 확률"을 단순한 **뺄셈**으로 바꿔준다는 점; (3) 연속 변수에 대해서는 밀도의 정확한 **역연산**이라는 점, 이것이 분포와 그 누적형태 사이를 마음대로 오갈 수 있게 해준다. 아래에서 이 각각을 살펴본다.

### 누적 합계 만들기

레시피는 "맨 왼쪽부터 $x$까지 분포를 누적한다"이다. 분포의 두 옷은 두 가지 구체적인 누적 방법을 준다.

**이산.** $x$ 이하인 모든 점의 질량을 더한다:

$$ F(x) = \sum_{x_i \le x} p(x_i), $$

여기서 기호 $\sum_{x_i \le x}$는 "$x_i \le x$를 만족하는 모든 지지점(support point) $x_i$에 대해 $p(x_i)$를 합한다"는 뜻이다("지지점"은 0이 아닌 질량을 갖는 값이다). $x$가 직선을 따라 오른쪽으로 미끄러질 때, $F$는 지지점 사이에서는 평평하게 유지되고 — 새로 더해지는 것이 없다 — $x$가 지지점 $x_i$를 지날 때마다 정확히 $p(x_i)$만큼 **위로 뛴다**. 그래서 이산 CDF는 **계단** 모양이다: 평평한 발판과, 각 값 $x_i$에서 높이 $p(x_i)$의 단이 있다.

**연속.** $x$까지 밀도 아래의 면적을 쓸어 담는다:

$$ F(x) = \int_{-\infty}^{x} f(t)\,dt, $$

여기서 $\int_{-\infty}^{x} f(t)\,dt$는 "곡선 $f$와 수평축 사이의 면적을, 맨 왼쪽부터 점 $x$까지 누적한 것"을 뜻한다. (안의 변수를 $t$로 바꾼 것은 오직 상한 $x$와 혼동되지 않도록 하기 위함이며, $x$ 아래의 모든 것을 훑는 더미 변수다.) 여기서 $F$는 **매끄럽게** 상승하며 뛰지 않는다. 왜냐하면 단일 점에서의 면적 조각을 더하는 것은 아무것도 기여하지 않기 때문이다 — 이는 연속 변수가 정확한 점 $c$에서 $P(X = c) = 0$이라는 전제 사실과 일치한다.

두 공식은 다른 산술로 표현된 같은 행위다: $x$ 아래의 점 가중치들을 *합하거나*, $x$ 아래의 면적을 *적분하는* 것. 둘 다 "$x$ 이하에 확률이 얼마나 놓여 있는가?"에 답한다.

### CDF가 왜 그런 모양이어야만 하는가

정의 $F(x) = P(X \le x)$와 분포에 관한 전제 사실들로부터 세 가지 성질이 강제된다. 이들은 관례가 아니라 각각 의미로부터 따라 나온다.

1. **결코 감소하지 않는다.** $b \ge a$이면, 사건 "$X \le a$"는 사건 "$X \le b$"에 *포함된다*(어떤 결과든 $a$ 이하이면 $b$ 이하이기도 하다). 더 큰 사건이 더 작은 확률을 가질 수는 없으므로, $F(b) \ge F(a)$다. $x$가 오른쪽으로 이동함에 따라 누적 합계는 평평하게 머물거나 오를 수만 있다 — 결코 떨어지지 않는다.

2. **0에서 시작해 1로 끝난다.** $x$를 맨 왼쪽으로 밀면($x \to -\infty$), 사건 "$X \le x$"는 "$X$가 모든 것보다 아래"가 되고, 이는 불가능하므로 $F(x) \to 0$이다. $x$를 맨 오른쪽으로 밀면($x \to +\infty$), 사건은 "$X$가 모든 것 이하"가 되고, 이는 확실하므로 $F(x) \to 1$이다. 이 끝점 값 1은 정확히 분포의 **정규화**다 — 전체 질량(합)이나 전체 면적(적분)이 1이라는 것 — 이제 "누적 합계가 모든 것을 다 쓸고 나면 전체 확률과 같다"로 읽힌 것이다. CDF는 0에서 1까지의 간격을 단조롭게 오른다.

3. **우연속(right-continuous)이다(그리고 이산의 도약은 원하는 곳에 정확히 놓인다).** 정의하는 부등식이 "$\le$"(이하, $x$ 자신을 *포함하여*)이기 때문에, 지지점 $x_i$에 *정확히* 놓인 질량은 $x$가 $x_i$에 도달하는 즉시 세어진다 — 그 이후가 아니라. 그래서 도약 지점에서 CDF는 *더 높은* 값을 취한다: $F(x_i)$는 이미 $p(x_i)$를 포함한다. 이것이 관례가 $P(X < x)$가 아니라 $P(X \le x)$인 기술적 이유이며, 아래의 구간 규칙이 깔끔하게 나오도록 만든다.

### 이점: 뺄셈으로 구하는 구간 확률

여기 핵심 항등식이 있다. $X$가 반열린 구간 $(a, b]$ — $a$보다 *크고* $b$ *이하* — 에 놓일 확률은

$$ P(a < X \le b) = F(b) - F(a). $$

**이유.** 사건 "$X \le b$"는 서로 배타적인 두 부분으로 나뉜다: "$X \le a$"와 "$a < X \le b$". 서로 배타적인 부분들의 확률은 더해지므로, $P(X \le b) = P(X \le a) + P(a < X \le b)$, 즉 $F(b) = F(a) + P(a < X \le b)$다. 재배열하면 구간을 분리해낸다: $P(a < X \le b) = F(b) - F(a)$. 누적 합계가 우리에게 이것을 사준 셈이다: $b$까지 누적된 전체에서 $a$까지 누적된 전체를 빼면, 정확히 그 *사이*에 놓인 확률이 남는다.

### 연속의 이점: 밀도는 CDF의 기울기다

연속의 경우 CDF와 밀도는 **역연산**이다. CDF는 면적을 누적한다: $F(x) = \int_{-\infty}^{x} f(t)\,dt$. "면적을 누적한다"의 역은 "면적이 더해지는 속도를 구한다"이며, 이는 미분이다. 미적분의 기본정리에 의해, 누적면적함수를 미분하면 누적되고 있던 곡선을 되돌려준다:

$$ f(x) = F'(x), $$

여기서 $F'(x)$는 $x$에서 $F$의 기울기 — 누적 합계가 그곳에서 얼마나 빠르게 오르고 있는지다. 이는 전제 개념인 "밀도는 단위 길이당 확률"의 정확한 의미다: $x$에서의 밀도는 문자 그대로 $x$가 나아감에 따라 확률이 쌓이는 *속도*다. $f$가 높은 곳에서는 $F$가 가파르고(확률이 빠르게 누적되고 있음), $f$가 0인 곳에서는 $F$가 평평하다(아무것도 더해지지 않음). 그래서 분포와 그 CDF는 한 대상을 바라보는 두 관점이며, 한 방향 적분/역방향 미분으로 연결되어 있다. 이 역연산 가능성이 CDF를 분포를 다루는 자연스러운 손잡이로 만든다.

### 거꾸로 읽기: 분위수와 중앙값

위의 모든 것은 *값* $x$를 *누적확률* $F(x)$에 대응시킨다. 이 함수를 거꾸로 읽으면 — 목표 확률에서 그것을 달성하는 값으로 — **분위수**(quantile)를 얻는다. 가장 친숙한 것은 **중앙값**이다: 누적 합계가 절반에 도달하는 값 $m$,

$$ F(m) = \tfrac{1}{2}, $$

이는 $X$가 $m$보다 아래 또는 위에 떨어질 확률이 각각 $\tfrac{1}{2}$로 동일하다는 뜻이다. 더 일반적으로, **역CDF**는 0과 1 사이의 확률 $q$를 받아 $F(x) = q$인 값 $x$를 반환한다 — 그 아래에 확률의 $q$ 비율이 놓이는 값이다. $F$가 0에서 1까지 단조롭게 오르기 때문에, $(0,1)$의 모든 목표 $q$에는 그런 값이 존재하며, 이 거꾸로 읽기는 잘 정의된다.

### 예시 (이산)

[[probability-distribution]]의 이산 분포를 다시 쓰자: 지지점 $\{1, 2, 3\}$에서 $X$가 다음 질량을 갖는다

$$ p(1) = 0.2, \qquad p(2) = 0.5, \qquad p(3) = 0.3 \quad (\text{합이 } 1). $$

$F(x) = \sum_{x_i \le x} p(x_i)$를 써서 왼쪽에서 오른쪽으로 누적한다. 구간별 계단:

- **$x < 1$:** 아직 $\le x$인 지지점이 없으므로, 합은 비어 있고 $F(x) = 0$이다.
- **$1 \le x < 2$:** 점 $1$만 해당하므로, $F(x) = p(1) = 0.2$이다.
- **$2 \le x < 3$:** 점 $1$과 $2$가 해당하므로, $F(x) = p(1) + p(2) = 0.2 + 0.5 = 0.7$이다.
- **$x \ge 3$:** 세 점 모두 해당하므로, $F(x) = 0.2 + 0.5 + 0.3 = 1.0$이다.

이는 진짜 계단이다(높이 $0.2$, $0.5$, $0.3$의 서로 다른 세 개의 단이며, 어떤 도약도 0이 아니므로 퇴화하지 않는다). 강제되는 성질을 확인해보자: 결코 감소하지 않는다($0 \le 0.2 \le 0.7 \le 1.0$); 0에서 시작해 1로 끝난다(정규화이며, 마지막 발판으로 읽힌다); 각 $x_i$에서의 도약은 더 높은 값에 놓인다 — $x = 2$에서, $F(2) = 0.7$은 이미 $p(2)$를 *포함하는데*, 정의가 "$\le$"를 쓰기 때문이다(우연속).

이제 확률을 읽어보자.
- $P(X \le 2) = F(2) = 0.7$이 곧바로 나온다.
- 뺄셈으로 구간을 구하면: $P(1 < X \le 3) = F(3) - F(1) = 1.0 - 0.2 = 0.8$이다. 질량으로 검산: $1 < X \le 3$은 $X \in \{2, 3\}$을 뜻하고, $p(2) + p(3) = 0.5 + 0.3 = 0.8$로 일치한다.

우연속이 요구하는 "$\le$ 대 $<$"의 세심함에 대한 참고: 여기서 $P(1 < X \le 3)$은 점 $1$을 제외하고 $3$을 포함한다. $F(1) = 0.7$을 대신 뺐다면 $2$에 있는 질량도 *함께* 빠졌을 것이므로 틀렸다 — $F(1) = 0.2$를 쓰면 $1$ 이하의 질량만 정확히 제거된다. 이산 변수에서는 끝점의 선택이 중요하며, CDF의 "$\le$" 관례가 뺄셈이 정확히 의도한 점들에 떨어지도록 만든다.

### 예시 (연속)

[[probability-distribution]]의 연속 분포를 쓰자: $X$는 $[0, 2]$에서 **균등**이며, 밀도는 $0 \le x \le 2$에서 $f(x) = 0.5$이고 그 외에는 $f(x) = 0$이다.

$F(x) = \int_{-\infty}^{x} f(t)\,dt$를 써서 면적을 누적한다. 구간별로:

- **$x < 0$:** 아직 면적이 없다(지지 구간 왼쪽에서 밀도가 0이므로), 그래서 $F(x) = 0$이다.
- **$0 \le x \le 2$:** 누적된 면적은 높이 $0.5$, 폭 $x - 0 = x$인 직사각형이므로, $F(x) = 0.5 \, x = x/2$다. 이는 매끄럽게 — 도약 없이 — $F(0) = 0$에서 $F(2) = 1$로 오른다.
- **$x > 2$:** 모든 면적(넓이 $0.5 \times 2 = 1$의 완전한 직사각형)이 이미 다 쓸려 담겼으므로, $F(x) = 1$이다.

성질을 확인하자: $F$는 결코 감소하지 않는다($[0,2]$에서 꾸준히 오르고 그 밖에서는 평평하다); 0에서 1까지 이어진다(끝점 1은 정규화 — 전체 면적); 어디서도 도약 없이 연속이며, 연속 변수에서 $P(X = c) = 0$인 것과 일치한다.

이제 이를 사용해보자.
- **미분해서 밀도를 되찾는다.** $[0, 2]$에서 $F(x) = x/2$이고, 그 기울기는 $F'(x) = 1/2 = 0.5 = f(x)$다. CDF의 도함수가 정확히 밀도를 돌려주며, $f = F'$를 확인해준다: 누적 합계는 단위 길이당 $0.5$의 일정한 속도로 오르는데, 이것이 바로 상수 밀도다.
- **중앙값을 구한다.** $F(m) = \tfrac{1}{2}$을 풀면: $[0,2]$에서는 $m/2 = 0.5$이므로 $m = 1$이다. 그래서 $1$이 중앙값이며 — 그 아래 또는 위에 떨어질 확률이 동일하다 — 이는 직관과 일치한다, $1$이 균등 범위 $[0, 2]$의 중점이기 때문이다.
- **뺄셈으로 구간을 구한다.** $P(0.5 < X \le 1.5) = F(1.5) - F(0.5) = 1.5/2 - 0.5/2 = 0.75 - 0.25 = 0.5$. 범위의 가운데 절반이 확률의 절반을 담고 있다 — 균등 변수에서는 그 구간이 $[0,2]$의 절반 길이이므로 다시 한번 예상대로다.

### 종합하기

CDF는 $F(x) = P(X \le x)$라는 하나의 함수로, 어떤 [[probability-distribution]]이든 맨 왼쪽에서 $x$까지 쓸어 담은 누적 합계로 재표현한다 — 이산 변수에는 합산된 계단, 연속 변수에는 매끄럽게 누적된 면적으로. 같은 세 가지 성질이 같은 이유로 두 옷 모두에서 성립한다: 결코 감소하지 않는다(더 큰 사건은 더 많은 확률을 담는다), 0에서 1로 오른다(끝점 1이 바로 정규화다), 우연속이다("$\le$"가 그 점 자체를 포함한다). 이 성질들이 이점을 벌어들인다: 두 옷 모두에서 뺄셈 $F(b) - F(a)$로 구하는 구간 확률; 연속 옷에서 기울기로서의 밀도 $f = F'$, 이는 CDF와 밀도를 역연산으로 만든다; 그리고 함수를 거꾸로 읽어서 얻는 중앙값 같은 분위수. 이것이 pmf나 pdf가 아니라 CDF가 분포를 다루는 통일된 손잡이인 이유다.
