# 도함수(Derivative)

## 요약

**도함수(derivative)** 는 함수의 순간 변화율을 측정한다 — 입력이 살짝 움직일 때
출력이 얼마나 빨리 움직이는지를.

## 상세 설명

$x$ 에서 $f$ 의 기울기는, 아주 작은 출력 변화를 그것을 일으킨 입력 변화로 나눈
비율이다 (차이를 차이로 나눈 것 — [[arithmetic]]):

$$f'(x) = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}$$

우리는 *극한(limit)* (입력 변화가 0으로 줄어드는 것)을 미적분의 바닥으로 삼고 거기서
멈춘다. 도함수가 양수이면 $f$ 는 오르고 있다는 뜻이고, 0이면 평평하다는 뜻 — 최적화가
최솟값이 어디 있는지 아는 방법이 바로 이것이다.
