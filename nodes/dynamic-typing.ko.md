# 동적 타이핑

## 요약

동적 타이핑(dynamic typing)은 데이터의 *타입* — 이것이 숫자인가, 문자열인가, 함수인가? — 이 값 자체에 붙어 프로그램이 실행되는 동안 참조되는 방식으로, 변수에 타입을 고정해 두고 사전에 검사하는 방식이 아니다. 실행 시점의 값은 사실상 하나의 쌍이다: 작은 **타입 태그(type tag)**와 실제 데이터(payload). 각 연산은 실행되는 바로 그 순간에 입력들의 태그를 읽고 무엇을 할지 결정한다(맞지 않으면 오류를 발생시킨다). 그 결과 하나의 변수가 지금은 숫자를, 나중에는 문자열을 담을 수 있고 타입 주석(type annotation)도 전혀 필요 없다 — 덕분에 유연하고 간결하며 빠르게 작성할 수 있는 코드가 된다 — 하지만 그 이면에는, 타입 불일치가 문제의 줄이 실제로 실행될 때에야 발견되고, 모든 연산이 태그를 검사하는 작은 비용을, 모든 값이 태그를 저장하는 작은 비용을 치른다는 대가가 있다. 이는 **정적 타이핑(static typing)**과 대비되는데, 정적 타이핑에서는 타입이 변수에 속하고 실행 전에 알려지며 불일치는 사전에 거부된다.

## 상세 설명

**핵심 질문: 타입은 어디에 사는가?** 모든 언어는 "이것의 타입은 무엇이고, 우리는 그것을 언제 알게 되는가?"에 답해야 한다. 정적 타이핑은 타입을 각 *변수*에 묶고 프로그램이 실행되기 *전에* 답을 확정한다(별도의 검사 단계가, `x`가 숫자로 선언되어 있다면 `x + "hello"`를 거부한다). 동적 타이핑은 타입을 각 *값*에 묶고 *프로그램이 실행되는 동안* 답을 확정한다. 동적 타입 언어에서 변수는 자기 자신의 타입이 없는 그저 이름일 뿐이며 — 어떤 타입의 값으로도 다시 바인딩될 수 있다 — 반면 실행 시점의 각 값은 데이터 옆에 태그를 지니고 다니기 때문에 자신이 무엇인지 알고 있다.

**왜 이런 설계인가 — 그리고 무엇을 치르는가.** 타입을 값에 붙이는 것이야말로 *같은* 이름이나 *같은* 컨테이너가 무엇이든 담을 수 있게 하는 원천이다: 리스트는 숫자와 문자열을 섞어 담을 수 있고, 함수는 어떤 타입이 오든 인자로 받을 수 있다. 작성할 타입 선언이 없으니 프로그램은 더 짧아지고 프로토타이핑은 더 빨라지며, 제네릭한 코드(예컨대 "길이를 가진 무엇에든" 동작하는 함수)가 공짜로 따라온다. 비용은 세 갈래이며 피할 수 없다: (1) 오류가 드러나는 *시점* — 타입 오류는 제어 흐름이 실제로 그 줄에 도달할 때까지 숨어 있으므로, 드물게 타는 분기 속의 실수는 눈치채지 못한 채 잠복할 수 있다; (2) *시간* — 각 연산은 동작하기 전에 피연산자들의 태그를 조사해야 한다; (3) *공간* — 모든 값이 태그를 끌고 다닌다. 이 설계는 실행-전-보장 안전성과 순수한 속도를 유연성과 간결함으로 맞바꾼다.

**구체적인 실례.** 동적 타입 언어에서 다음을 생각해 보자:

```
x = 10          -- x now holds a value tagged "number"
x = "ten"       -- perfectly legal: same name, now a value tagged "string"
```

`x`를 숫자에서 문자열로 다시 바인딩하는 것은 문제없다 — 타입은 `x`가 아니라 값에 속하기 때문이다. 이제:

```
y = x + 1
```

`+`가 실행되는 순간, 그것은 `x`의 현재 값의 태그를 조사한다. `x`가 숫자를 담고 있으면 더한다. `x`가 `"ten"`(문자열)을 담고 있으면, `+`는 숫자를 기대한 자리에서 문자열 태그를 보고 **런타임(runtime)** 타입 오류를 발생시킨다 — 사전이 아니라 바로 그 순간에. 퇴화하지 않은(non-degenerate) 대목: 그 `+`를 절대 실행되지 않는 분기 안에 넣으면 —

```
if false then y = x + 1 end     -- never runs
```

— `x`가 문자열인데도 프로그램은 아무 오류 없이 끝까지 실행된다. 이것이 동적 타이핑을 정의하는 행동이다: 검사가 그 연산의 *실행*에 묶여 있다. 정적 타이핑이라면 바로 그 `x + 1`은, 분기를 타든 안 타든, 프로그램이 시작되기도 전에 거부되었을 것이다.
