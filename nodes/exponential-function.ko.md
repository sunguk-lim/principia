# 지수 함수

## 요약

**지수 함수**(exponential function) $e^{x}$ 는 자기 자신의 값에 비례하여 증가하며, 항상
양수이고 덧셈을 곱셈으로 바꾼다.

## 상세 설명

[[arithmetic]] (반복 곱셈을 모든 실수로 확장한 것) 위에 세워진다:

$$e^{x} = \sum_{k=0}^{\infty} \frac{x^{k}}{k!}, \qquad e^{x} > 0 \ \text{ for all } x,
\qquad e^{x+y} = e^{x}\,e^{y}$$

이후 단계에서 중요한 성질은 두 가지다: 지수 함수는 **항상 양수**이며(따라서 어떤
실수 점수든 양의 가중치로 바꿀 수 있다) **단조**(monotonic)이다(입력이 커지면 출력도
커진다). 이것이 바로 소프트맥스가 점수를 확률로 변환하는 데 필요한 성질이다.
