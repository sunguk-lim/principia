# 그래프 최적화 (Graph Optimization)

## 요약

**그래프 최적화(graph optimization)**는 [[computation-graph]]를 같은 결과를 내면서
계산량이나 데이터 이동이 더 적거나 대상 실행기에 더 잘 맞는 그래프로 다시 쓴다.
구조는 바뀌지만 허용되는 모든 입력은 여전히 같은 결과를 만들어야 한다.

## 상세 설명

[[computation-graph]]는 계산 구조를 명시한다. 그 [[graph]] 뼈대는 도구가 실행 전에 바꿀
수 있는 노드와 간선을 제공한다.
재작성은 알려진 패턴을 찾고, 대체가 유효한 조건을 확인한 뒤, 더 저렴한 패턴으로 바꾼다.
핵심 불변 조건은 **의미 보존(semantic preservation)**이다. 최적화는 노드와 간선을 바꿀
수 있지만 그래프 출력에서 관찰되는 계산은 바꾸면 안 된다.

세 가지 일반적인 재작성이 이 원리를 보여 준다. **상수 접기(constant folding)**는 입력이
모두 고정 상수인 영역을 미리 계산해 결과를 저장하므로 실행 중에는 그 영역을 계산하지
않는다. **제거(elimination)**는 항등 연산이나 중복 노드를 없애고 입력을 소비자에게 직접
연결한다. **융합(fusion)**은 `MatMul → Add` 같은 연쇄를 중간값을 실체화하지 않고 두
연산을 함께 수행하는 노드 하나로 바꾼다. 배치 재작성은 선택된 실행기가 더 빠르게 처리할
수 있도록 값의 배열을 바꿀 수 있다.

**구체적인 예.** `x → Identity → Add(2, 3) → Multiply`에서 시작하자.
`Add(2, 3)`을 상수 접기하면 상수 `5`가 된다. `Identity`를 제거하면 `x`가
`Multiply`에 바로 연결된다. 원래 경로는 노드 3개를 실행하지만 최적화된 경로는
`Multiply(x, 5)` 하나만 실행한다. `x = 4`일 때 두 경로 모두 `20`을 반환하지만,
최적화된 그래프는 실행 중 연산 두 개를 피한다. 이 등식이 예시뿐 아니라 모든 유효한
`x`에 대해 성립하므로 재작성은 유효하다.
