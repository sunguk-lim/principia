# 선형 독립

## 요약

벡터들의 집합이 **선형 독립(linearly independent)**이라는 것은 그중 어느 것도
다른 것들의 조합으로 표현될 수 없다는 뜻이다 — 각 벡터가 진정으로 새로운 방향을
더한다.

## 상세 설명

벡터 $v_1,\dots,v_k$가 선형 독립이라는 것은, 이들을 결합하여(스칼라를 곱하고
더하는 것 — 즉 [[arithmetic]]) 0에 도달하는 유일한 방법이 자명한 방법뿐이라는 뜻이다:

$$\sum_{i=1}^{k} c_i v_i = 0 \;\Rightarrow\; c_1 = c_2 = \dots = c_k = 0$$

만약 자명하지 않은 어떤 조합이 0을 준다면, 벡터 하나는 중복된 것이다. 선형 독립인
행(또는 열)의 개수가 정확히 행렬-랭크가 세는 것이다.
