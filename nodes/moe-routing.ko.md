# MoE 라우팅

## 요약

라우팅(routing)은 각 토큰에 어떤 전문가 변환을 어떤 가중치와 용량 규칙으로 적용할지 정한다. [[mixture-of-experts]]에서 학습된 토큰 선택 상위 k(top-k)는 흔한 방식이지만 모든 라우터의 정의는 아니다. 전문가 선택, 고정 매핑, 부드러운 토큰 혼합은 서로 다른 선택 계약을 사용한다.

## 상세 설명

### 토큰 선택 점수와 출력 가중치

일반적인 토큰 선택 게이트는 토큰의 은닉 벡터에 학습된 행렬을 곱해 전문가 점수를 얻는다. [[softmax]]로 선호도를 정규화하고 상위 k개를 남긴다. 선택된 가중치를 다시 정규화할지는 모델별 규칙이다. 선택 점수와 출력 혼합 가중치가 같을 필요도 없다. DeepSeek-V3는 균형 조절 편향을 선택에 사용하되 출력 가중치는 원래 친화도에서 구한다. 고정 k는 선택된 전문가 평가 수를 제한할 뿐 저장 공간, 전체 라우팅 작업량, 실제 지연을 고정하지 않는다.

독립적인 상위 두 개 예로 선호도 [.50,.30,.20]이면 전문가 1과 2가 선택된다. 선택 후 재정규화 규칙에서는 .50/.80=.625와 .30/.80=.375가 된다. 두 전문가의 스칼라 출력이 4와 8이면 결과는 .625*4+.375*8=5.5다. 원래 가중치를 마스킹만 하면 .50*4+.30*8=4.4다. 체크포인트가 학습한 규칙을 임의로 바꿔서는 안 된다.

### 용량과 초과 처리

전문가 용량은 서로 다른 토큰 수가 아니라 토큰-전문가 할당 수를 셀 수 있다. T개 토큰이 E개 전문가 중 각각 k개를 선택하면 할당은 T*k개이고 전문가당 평균은 T*k/E다. 한 가지 예시 상한은 c*T*k/E를 올림한 값이며 c는 용량 계수다. 구현마다 정의, 반올림, 적용 단계가 다르므로 실제 공식을 확인해야 한다.

T=6, k=2, E=4, c=1이면 할당은 12개, 전문가별 상한은 3이다. 요청 부하가 [5,3,2,2]이면 전체 용량이 충분해도 첫 전문가에 두 할당이 초과된다. 드롭 정책은 이 두 분기의 기여를 제거하고, 재라우팅은 목적지를 바꾸며, 드롭 없는 구현은 불균형한 작업을 할당하거나 스케줄링한다. 계산 의미와 비용이 서로 다르다. 한 분기를 잃은 토큰도 다른 전문가의 출력과 잔차 경로가 남을 수 있어 토큰 전체가 삭제되거나 완전히 그대로 통과한다고 단정할 수 없다.

학습 시 균형 목적은 분포를 유도할 뿐 모든 서빙 배치의 균형을 보장하지 않는다. 용량 제한은 학습과 추론 모두에 사용될 수 있다. 드롭은 필수가 아니고 품질 손실이 항상 작지도 않다. DeepSeek-V3 보고서의 학습 및 추론 무드롭 설계는 해당 시스템의 계약이지 모든 희소 모델의 보장은 아니다.

### 검증

학습과 추론의 선택을 따로 명시하고 그룹, 인과성, 가중치, 동점, 용량, 빈 선택 및 초과 처리를 포함한다. 전문가별 부하, 토큰별 처리 범위, 드롭 할당, 과제 품질과 전체 디스패치·연산·결합 지연을 측정한다. 같은 토큰 수가 같은 전문가 실행 시간을 뜻하지 않으며 수치상 균형도 더 빠른 응용을 증명하지 않는다. 같은 체크포인트와 품질 계약으로 비교해야 한다. 학습 후 라우팅 변경은 학습된 함수를 바꿀 수 있다.
