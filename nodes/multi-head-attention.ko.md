# 멀티 헤드 어텐션(Multi-Head Attention)

## 요약

멀티 헤드 어텐션은 [[transformer-attention]]을 서로 다른 학습 투영 공간에서 병렬로 계산한 뒤 결과를 합친다. 헤드마다 별도로 정규화하므로 여러 가중 패턴을 동시에 표현할 수 있다. 총 너비를 고정하면 주요 행렬 연산량은 비슷하지만, 실제 지연 시간이나 품질이 같다는 보장은 없다.

## 상세 설명

입력 X는 토큰 수 n, 모델 너비 d인 n×d 행렬이다. 헤드 수를 h, 헤드 너비를 d_head=d/h라 하자. 각 헤드의 W_q, W_k, W_v는 d×d_head이고, 출력 투영 W_o는 d×d이다. [[matrix-multiplication]]으로 입력을 헤드별 Q/K/V로 투영하고 [[transformer-attention]]을 적용한다. 각 결과는 n×d_head이며, 이를 이어 붙여 n×d로 만들고 W_o로 섞는다.

MHA(X)=Concat(head_1,…,head_h)W_o이며 head_i=Attention(XW_q^i,XW_k^i,XW_v^i)다. 한 헤드는 질의마다 하나의 가중 분포를 만들고, 여러 헤드는 서로 다른 학습 투영과 별도 [[softmax]]를 통해 여러 패턴을 만들 수 있다. 헤드가 반드시 특정 의미 역할을 학습하는 것은 아니다. d_head=d/h일 때 헤드별 투영을 합치면 d×d가 되므로 주요 투영 파라미터 수와 행렬 연산량은 유지되지만 정규화, 저장 및 커널 비용까지 무료가 되는 것은 아니다.

### 계산 예

d=4, h=2, d_head=2이고 토큰 두 개를 사용한다. 첫 헤드는 앞의 두 좌표를, 두 번째는 뒤의 두 좌표를 선택한다고 하자. 헤드 1의 질의는 [1,0], 키는 [1,0]과 [0,1], 값은 [2,0]과 [0,2]다. 점수 [1,0]을 √2로 나누면 약 [0.71,0]이고 softmax는 [0.67,0.33]이다. 가중합은 [1.34,0.66]이다.

헤드 2는 질의 [0,1], 같은 키, 값 [3,0]과 [0,3]을 사용한다. 점수 [0,1]을 √2로 나눈 뒤 정규화하면 [0.33,0.67]이고 결과는 [0.99,2.01]이다. 두 결과를 이어 붙이면 [1.34,0.66,0.99,2.01]이며 W_o가 단위행렬이면 이것이 최종 출력이다. 같은 토큰들에 대해 두 헤드가 서로 다른 가중 패턴을 만들었다.

하드웨어에서는 여러 헤드를 묶어 행렬 연산하지만 단일 넓은 헤드보다 느리지 않다는 보장은 없다. 각 헤드의 키와 값은 생성 과정에서 저장되며, 캐시 비용은 키/값 헤드 수와 너비를 함께 계산해야 한다.

## 고정 너비, 랭크 및 실행 형태

Q/K/V의 총 너비가 모두 d인 밀집 투영을 가정하면, 편향을 제외한 전체 투영 가중치는 4d²개다. d=2,048일 때 16헤드는 너비 128, 32헤드는 너비 64이며 둘 다 16,777,216개의 투영 가중치를 갖는다. 같은 개수는 같은 함수 표현력이나 학습 품질을 뜻하지 않는다.

마스크 이전의 Q와 K가 T×d_head이면 QK 전치 곱의 [[matrix-rank]]는 d_head 이하다. 그러나 행별 softmax는 비선형이며 마스크도 점수를 바꾸므로 이 한계를 최종 어텐션 행렬에 그대로 적용할 수 없다. 점수 [[0,0],[0,1]]은 랭크 1이지만 정규화 결과는 약 [[0.5,0.5],[0.269,0.731]]이다. [[determinant|행렬식]]이 약 0.231이므로 랭크는 2다. 이는 무제한 표현력의 증명이 아니라 원시 점수의 랭크 한계를 비선형 연산 뒤로 옮길 수 없다는 반례다.

d가 같으면 주요 어텐션 행렬 연산은 T²d에 비례하지만, 점수를 물리적으로 저장할 경우 원소 수는 hT²이다. 융합 커널은 전체 점수 저장을 피할 수 있어도 형태에 따른 정규화, 데이터 이동 및 스케줄링 비용은 남는다. 보편적인 최적 헤드 너비는 없다. 같은 예산으로 재학습한 대안을 품질과 커널 실행 흔적, 메모리, 프리필/디코드 시간으로 비교하라. 학습 후 가지치기는 새 아키텍처의 헤드 수 선택과 다른 실험이다.
