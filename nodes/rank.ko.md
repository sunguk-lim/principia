# 랭크

## 요약

**랭크(rank)**는 [[communicator]]가 자신의 구성원 프로세스 각각에게 부여하는
**정수 id**로, `n`개 프로세스로 이루어진 그룹이라면 `0, 1, …, n-1`이다. 이것은
프로세스가 *지칭되는* 방식이다: 해당 communicator 안에서 "랭크 2"는 특정한 하나의
프로세스를 명확하게 가리킨다. 프로세스는 또한 "내 랭크가 무엇인가?"를 물어봄으로써
자신이 그룹의 어느 구성원인지 알아낼 수 있다.

## 상세 설명

[[communicator]]는 프로세스들의 그룹을 고정하고 이들에게 번호를 매긴다. 그 번호가
곧 랭크이며, 랭크는 두 가지 역할을 한다:

1. **주소로서의 역할.** 특정 프로세스에게 보내려면 그것의 랭크를 지명하고, 하나를
   (예컨대 루트로서) 특정하려면 그것의 랭크를 준다. 랭크는 추상적인 "다른 프로세스"를
   구체적인 대상으로 바꾸어 준다.
2. **정체성으로서의 역할.** 모든 구성원이 *같은* 프로그램을 실행하기 때문에,
   프로세스는 자신의 랭크를 이용해 무엇을 할지 결정한다 — "내 랭크가 0이면 나는
   소스이고, 그렇지 않으면 수신자다." 랭크는 그 외에는 동일한 프로세스들이 자신의
   동작을 특수화하는 방법이다.

랭크는 오직 **[[communicator]]에 대해 상대적으로만** 의미를 가진다: 동일한 물리적
프로세스가 서로 다른 communicator 안에서는 다른 랭크를 가질 수 있다. 하나의
communicator 안에서, 랭크 `0 … n-1`은 정확히 "모든 프로세스"의 집합이며, 이것이
집합적 연산이 모든 랭크를 지칭함으로써 그룹 전체에 작용할 수 있게 해준다.

이 노드는 [[communicator]] → message-passing → parallel-process로 이어지며 닫히므로,
어떤 부분도 설명되지 않은 채 남지 않는다.
