# RMSNorm

## 요약

**RMSNorm**(제곱평균제곱근 정규화, root-mean-square normalization)은
[[neural-network]]의 층과 층 사이에 놓이는 작은 층으로, 각 활성화 벡터를
안정적인 크기로 다시 조정한다: 벡터를 그 제곱평균제곱근으로 나눈 다음, 각
좌표에 학습된 이득(gain)을 곱한다. 활성화 값을 일정한 스케일 근처로 유지하면
학습이 잘 조건화(well-conditioned)된 상태로 유지되며, RMSNorm은 이를 예전의
LayerNorm보다 더 적은 연산으로 수행하기 때문에 현대 대형 언어 모델에서
표준적인 정규화 층이 되었다.

## 상세 설명

[[neural-network]]에서 살펴본 것처럼, 하나의 층은 벡터를 받아 가중치 행렬을
곱하고 편향을 더한 뒤 비선형 함수를 적용하며, 이런 층들이 여러 개 쌓인다. 각
층의 출력은 **활성화 벡터(activation vector)**다: 다음 층으로 전달되는 숫자의
목록이다. 이 벡터들이 깊은 층 스택을 통과하면서 전체적인 크기가
표류(drift)할 수 있다 — 층을 거칠수록 커지거나 작아질 수 있다 — 그리고 이
표류는 학습을 불안정하게 만드는데, 한 층이 만들어야 할 갱신의 크기가 그
층에 도달하는 숫자들의 크기에 좌우되기 때문이다. **정규화 층(normalization
layer)**은 다음 층이 보기 전에 각 활성화 벡터를 예측 가능한 크기로 다시
조정함으로써 이 문제를 해결한다.

**핵심 대상.** RMSNorm은 벡터의 *제곱평균제곱근(root mean square)*으로
정규화한다. 활성화 벡터를 $x = (x_1, x_2, \dots, x_d)$로 쓰자. 여기서 $d$는
그 **차원(dimension)**(좌표의 개수)이다. 제곱평균제곱근은 좌표들의 제곱의
평균에 제곱근을 취한 값이다.

$$\mathrm{RMS}(x) = \sqrt{\tfrac{1}{d}\sum_{i=1}^{d} x_i^2}.$$

여기서 $\sum_{i=1}^{d} x_i^2$는 "$d$개 좌표 모두의 제곱을 더한다"는 뜻이고,
$\tfrac{1}{d}$는 그것들을 평균낸다. RMS는 $x$의 좌표가 일반적으로 얼마나 큰지를
측정하는 하나의 양수다. RMSNorm은 모든 좌표를 이 값으로 나눈다.

$$\hat{x}_i = \frac{x_i}{\mathrm{RMS}(x)}.$$

이 나눗셈 후 다시 조정된 벡터 $\hat{x}$는 $x$가 원래 얼마나 크거나 작았든
상관없이 제곱평균제곱근이 정확히 $1$이 된다. 이것이 RMSNorm이 유지하는
**불변량(invariant)**이다: 모든 활성화 벡터는 단위 RMS 상태로 층을
떠나므로, 이후 층들은 항상 같은 스케일의 숫자를 받는다.

**왜 작동하는가, 그리고 무엇을 보존하는가.** 하나의 양수로 나누는 것은
벡터의 *방향*을 바꾸지 않는다 — 오직 *길이*만 바꾼다. 그래서 RMSNorm은
$x$의 크기(표류를 일으키고 문제를 만드는 부분)는 버리면서, 좌표들 사이의
상대적 값 패턴(정보를 담고 있는 부분)은 그대로 유지한다. 이것이 바로 이
개념에서 자명하지 않은 지점이다: 스칼라로 다시 조정하는 것이 여기서 중요한
유일한 의미에서 정보를 보존하는데, 왜냐하면 활성화의 의미 있는 내용은
좌표들의 *절대 크기*가 아니라 그 사이의 *비율*에 담겨 있기 때문이다.

**학습된 이득.** 고정된 단위 스케일이 다음 층이 항상 원하는 것은 아니므로,
RMSNorm은 **이득(gain)** 벡터 $g = (g_1, \dots, g_d)$로 유연성을 되살린다 —
[[neural-network]]의 다른 파라미터와 마찬가지로 학습 중에 조정되는, 좌표당
하나씩 학습된 숫자다. 최종 출력은 좌표별로 곱한다.

$$y_i = g_i \,\hat{x}_i = g_i \,\frac{x_i}{\mathrm{RMS}(x)}.$$

(실제로는 $x$가 전부 0일 때 0으로 나누는 것을 피하기 위해 제곱근 안에 아주
작은 상수 $\varepsilon$을 더하는데, 이는 개념 자체를 바꾸지 않는다.)

**LayerNorm과의 대비 — "왜 연산이 더 적은가".** RMSNorm이 대체한 층은
**LayerNorm**인데, 이는 세 가지 일을 한다: 좌표들의 *평균*을 빼고(벡터를
0을 중심으로 다시 정렬), *표준편차*(그 평균 주위 좌표들의 퍼짐 정도)로
나누며, 학습된 *편향(bias)* 벡터를 더한다. RMSNorm은 다시 조정만 남기고 나머지
둘은 버린다: 평균을 계산하지 않고, 재정렬도 하지 않으며, 편향도 없다. 그
대가는 RMSNorm이 더 저렴하다는 것이다 — 평균을 계산하고 재정렬하는 것은 모든
좌표에 대해 추가 연산이 필요한데, RMSNorm은 이를 건너뛴다 — 그럼에도 현대
모델 전반에서 학습 성능은 뒤지지 않는다. 더 저렴하면서도 더 나쁘지 않다는
그 조합이 RMSNorm이 LayerNorm을 상당 부분 대체한 이유다.

**구체적인 예.** 활성화 벡터 $x = (3, 0, 4)$를 예로 들면, $d = 3$이다. 각
좌표를 제곱하면: $3^2 = 9$, $0^2 = 0$, $4^2 = 16$. 이를 더하면: $9 + 0 + 16 =
25$. 세 좌표에 대해 평균을 내면: $25 / 3 = 8.333$. 제곱근을 취하면:
$\mathrm{RMS}(x) = \sqrt{8.333} = 2.887$. 이제 각 좌표를 $2.887$로 나누면:

$$\hat{x} = \left(\tfrac{3}{2.887},\ \tfrac{0}{2.887},\ \tfrac{4}{2.887}\right)
= (1.039,\ 0,\ 1.386).$$

이득이 $g = (1, 1, 1)$이면 출력은 $\hat{x}$ 자체와 같다. 두 가지를 주목하자.
가운데 좌표는 $0$이었고 그대로 $0$으로 남는다. 첫 번째와 세 번째 좌표는
비율을 유지한다: 이전에는 $3 : 4$였고, 이후에는 $1.039 : 1.386$으로 여전히
같은 $3 : 4$다. 즉 벡터의 *방향*은 그대로이고, *스케일*만 $2.887$의 RMS에서
$1$의 RMS로 바뀌었다. 이것이 바로 RMSNorm이 약속하는 동작이다: 크기는
고정하고 의미는 그대로 둔다.

**어디에 위치하는가.** LLaMA나 Mamba 같은 현대 모델에서는 RMSNorm 층이 각
블록의 입구에 위치하여, 활성화 벡터를 같은 형태의 벡터로 매핑하되 정규화하고
이득으로 다시 조정한 뒤, 블록의 더 무거운 계산이 실행되기 직전에 놓인다.
이는 [[neural-network]]의 나머지 부분이 수치적으로 안정적인 상태를
유지하는 데 의존하는 가벼운 조건화 단계다.
