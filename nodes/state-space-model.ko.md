# 상태 공간 모델

## 요약

**상태 공간 모델(state space model, SSM)**은 고정된 크기의 **은닉 상태(hidden
state)**를 *학습 가능한 선형 순환(linear recurrence)*을 통해 시간에 따라 이어
나가는 시퀀스 모델이다. 매 스텝마다 상태는 이전 상태와 새 입력을 가중 결합한
값이 되고, 출력은 그 상태로부터 읽어낸다. 이 순환이 **선형**이기 때문에, 동일한
모델이 정확히 동등한 두 가지 형태를 갖는다 — 토큰을 한 번에 하나씩 생성할 때
쓰는 값싼 스텝별 순환 형태와, 학습 시 전체 시퀀스를 병렬로 처리하는 단일 고정
컨볼루션 커널 형태다. 이 모델의 핵심 미덕은 시퀀스 길이와 무관하게 상태의
*크기가 고정되어 있다는 것*이며, 그 덕분에 시퀀스가 길어져도 스텝당 비용과
메모리가 일정하게 유지된다.

## 상세 설명

### 무엇인가, 그리고 왜 그냥 신경망이 아닌가

[[neural-network]]는 하나의 입력을 하나의 출력에 대응시킨다: $x$를 넣으면
$f(x)$를 돌려준다. 여기에는 *시퀀스*나 *이어지는 기억*이라는 개념이 내장되어
있지 않다 — 문장의 열 번째 단어를 보여주면 앞의 아홉 단어는 이미 잊어버린
상태다. 상태 공간 모델은 바로 이 빠진 조각을 채운다: 한 스텝에서 다음 스텝으로
이어지며 지금까지 본 모든 것을 하나의 고정 크기 벡터로 요약하는 **상태**
$h$다. 모델 *자체*가 이 순환이다; 그 안의 선형 사상은 신경망 가중치 행렬로
공급될 수도 있지만, 여기서 다루는 개념은 그 사상이 아니라 **순환 구조**
그 자체다.

**기호표** (🟦 스칼라 · 🟩 벡터 · 🟧 행렬):

| 기호 | 유형 | 의미 |
| --- | --- | --- |
| $t$ | 🟦 | 시간 스텝(시퀀스 내 위치), $t = 1, 2, \dots, n$ |
| $n$ | 🟦 | 시퀀스 길이 |
| $x_t$ | 🟩 | 스텝 $t$에서의 입력 (아래 예제에서는 🟦) |
| $h_t$ | 🟩 | 스텝 $t$ 이후의 은닉 **상태** (예제에서는 🟦) |
| $y_t$ | 🟩 | 스텝 $t$에서의 출력 (예제에서는 🟦) |
| $A$ | 🟧 | **상태 전이** 사상: 이전 상태가 얼마나 다음으로 이어지는지 |
| $B$ | 🟧 | **입력** 사상: 새 입력이 상태로 어떻게 들어가는지 |
| $C$ | 🟧 | **출력** 사상: 상태를 어떻게 읽어내는지 |
| $D$ | 🟧 | 선택적인 입력-출력 직접 사상 (스킵 연결) |

전체 모델은 매 스텝에 적용되는 두 개의 식으로 이루어진다:

$$h_t = A\,h_{t-1} + B\,x_t \qquad\qquad y_t = C\,h_t + D\,x_t$$

말 그대로 읽으면: 새 상태 $h_t$는 **$A$만큼 스케일된 이전 상태**(감쇠하거나
유지되는 기억)에 **$B$를 통해 주입된 새 입력**을 더한 것이고, 출력 $y_t$는
상태를 **$C$를 통해 읽어낸 값**이다(선택적으로 $D$를 통한 원시 입력이 더해질
수 있다). 행렬 $A, B, C, D$는 *모든 시간 스텝에 걸쳐 고정*되어 있으며 학습되는
파라미터다. 상태 $h$는 절대 커지지 않는다: 스텝 $3$이든 스텝 $3{,}000$이든
$h$는 같은 크기다. 이것이 핵심이다 — 이 모델은 무한히 늘어나는 과거를 유한한
요약으로 압축한다.

### 왜(WHY): 선형성이 사주는 두 가지 동등한 형태

위 순환은 **자기회귀적(autoregressive)**이다 — $h_t$를 얻으려면 $h_{t-1}$이
필요하므로 왼쪽에서 오른쪽으로 한 스텝씩 진행되며, 스텝당 작업량과 메모리는
$O(1)$이다. 이는 *추론*(다음 토큰 생성)에는 이상적이지만 병렬화할 수 없다:
스텝 $t$는 스텝 $t-1$을 기다려야 한다.

여기서 겉보기엔 마법 같은, 그러나 결코 자명하지 않은 단계가 등장한다.
순환이 **선형**이기 때문에(스텝 사이에 비선형이 끼어 있지 않으므로),
이를 닫힌 형태로 펼칠 수 있다. $h_0 = 0$에서 시작하면:

$$h_t = \sum_{j=1}^{t} A^{\,t-j} B\, x_j, \qquad
  y_t = C h_t = \sum_{j=1}^{t} \big(C A^{\,t-j} B\big)\, x_j.$$

펼쳐진 각 항은 그저 순환의 기하학적 연쇄일 뿐이다: 입력 $x_j$는 스텝 $j$에서
$B$를 통해 상태로 들어갔고, 그 이후 $t-j$번의 스텝 동안 매번 $A$가 곱해졌으며,
마지막으로 $C$에 의해 읽혔다. **위 식이 바로 그 정당화 근거다**: 출력은 과거
모든 입력의 가중합이며, $k = t-j$ 스텝 전에 도착한 입력에 걸리는 가중치는

$$k_k = C A^{\,k} B.$$

이 가중치들 $(k_0, k_1, k_2, \dots) = (CB,\ CAB,\ CA^2B,\ \dots)$은 지연
$k$에만 의존하며 절대 시간에는 의존하지 않는다. 따라서 전체 출력 시퀀스는
입력과 하나의 고정 커널 간의 **컨볼루션**이 된다 — 모든 위치에 동일한
커널이 쓰인다. 이는 학습 중에는 *모든* $y_t$를 병렬로(전체 시퀀스에 대한
한 번의 컨볼루션으로) 계산할 수 있고, 추론 시에는 값싼 스텝별 순환으로
전환할 수 있음을 의미한다. **순환과 컨볼루션은 같은 모델의 두 얼굴**이며,
선형성이 바로 이 둘을 같게 만드는 이유다.

이를 어텐션과 대비해보면, 어텐션은 모든 위치를 다른 모든 위치와 비교하며
$O(n^2)$의 비용이 든다. SSM의 순환은 전체 $O(n)$이며 상태는 $O(1)$이다 —
과거는 요약될 뿐, 다시 훑지 않는다.

### 예제로 풀어보기 — 같은 $y$를 두 가지 방식으로

1차원 상태(모든 것이 스칼라)를 가정하고 $A = 0.5$, $B = 2$, $C = 3$,
$D = 0$, 입력 $x = [\,1,\ 0,\ 2\,]$, $h_0 = 0$으로 두자. 확인해야 할
분기는 다음과 같다: 이전 상태의 $A$-감쇠가 실제로 최소 두 스텝에 걸쳐
이어져야 하고, *0*인 입력도 이전 상태를 계속 전파해야 하며, 뒤에 오는
큰 입력이 감쇠된 잔향과 섞여야 한다 — 이 예제는 이 세 가지를 모두
보여준다.

**방식 1 — 순환**, 스텝별로:

- $h_1 = A h_0 + B x_1 = 0.5(0) + 2(1) = 2,\quad\; y_1 = C h_1 = 3(2) = 6$
- $h_2 = A h_1 + B x_2 = 0.5(2) + 2(0) = 1,\quad\; y_2 = C h_2 = 3(1) = 3$
- $h_3 = A h_2 + B x_3 = 0.5(1) + 2(2) = 4.5,\; y_3 = C h_3 = 3(4.5) = 13.5$

$x_2 = 0$인데도 $y_2 = 3$임에 주목하라: 상태는 여전히 $x_1$을 기억하고
있으며, $A$에 의해 한 번 감쇠되었을 뿐이다. 그리고 $y_3 = 13.5$는 새로
들어온 $x_3 = 2$와 두 번 감쇠된 $x_1$의 잔향을 섞은 값이다. 출력은
$y = [\,6,\ 3,\ 13.5\,]$.

**방식 2 — 컨볼루션**, 고정 커널 $k_k = C A^k B$를 사용:

$$k_0 = CB = 3 \cdot 2 = 6,\quad k_1 = CAB = 3(0.5)(2) = 3,\quad k_2 = CA^2B = 3(0.25)(2) = 1.5.$$

이제 $y_t = \sum_{j=1}^{t} k_{t-j}\, x_j$이므로:

- $y_1 = k_0 x_1 = 6(1) = 6$
- $y_2 = k_0 x_2 + k_1 x_1 = 6(0) + 3(1) = 3$
- $y_3 = k_0 x_3 + k_1 x_2 + k_2 x_1 = 6(2) + 3(0) + 1.5(1) = 13.5$

동일하다: $y = [\,6,\ 3,\ 13.5\,]$. $y_3$에서 $x_1$에 걸리는 커널 값
$1.5$는 정확히 $C A^2 B$다 — 두 스텝 전에 들어온 입력이 $A$에 의해 두 번
감쇠된 것으로, 순환 방식에서 본 것과 같은 잔향이다. 하나의 모델, 두 개의
동등한 계산: 값싼 생성을 위한 순환과 병렬 학습을 위한 컨볼루션.

이 선형 순환과 컨볼루션의 결합 구조는 Mamba(다른 노드에서 다룬다)와 같은
현대적 장시퀀스 아키텍처의 토대이며, Mamba는 이 핵심 구조를 유지하면서
$A, B, C$ 사상이 입력에 의존하도록 만든다.
