# 대칭-반대칭 분해

## 요약

정사각행렬 `M`(행과 열의 개수가 같은 숫자 격자)은 항상 정확히 하나의 방식으로
더해지는 두 조각으로 나뉜다: 주대각선을 기준으로 뒤집어도 변하지 않는 *대칭*
부분 `S`와, 그 뒤집기 아래에서 자기 자신의 음수가 되는 *반대칭* 부분 `A`이다.
공식은 `S = ½(M + Mᵀ)`와 `A = ½(M − Mᵀ)`이며, 여기서 `Mᵀ`는 대각선을 기준으로
`M`을 뒤집은 것이다. 이것이 중요한 이유: `M`이 흐르는 유체가 어떤 점 근처에서
어떻게 늘어나고 회전하는지를 기술할 때, `S`는 *늘어남과 전단*(작은 원이 어떻게
타원으로 찌그러지는지)을 모두 담아내고, `A`는 순수한 *회전*(덩어리가 얼마나
빠르게 도는지)을 담아낸다 — 왜곡과 회전을 깔끔하게 갈라내는 한 번의 절단이다.

## 상세 설명

중심 대상부터 시작하자. *정사각행렬* `M`은 행과 열의 개수가 같은 숫자 격자이다;
`M[i][j]`는 행 `i`, 열 `j`에 있는 숫자를 나타낸다고 쓰자. *주대각선*은 행 번호와
열 번호가 같은 항목들의 줄, `M[1][1], M[2][2], …`이다.

여기에 더해 우리가 필요로 하는 유일한 연산은 **전치**이며, `Mᵀ`로 쓴다. 이는
`M`을 주대각선을 기준으로 반사하여 얻는 행렬이다: `Mᵀ`의 행 `i`, 열 `j`에 있는
항목은 원래 행렬의 행 `j`, 열 `i`에 있는 항목이다. 즉 `Mᵀ[i][j] = M[j][i]`이다.
대각선 항목은 그대로 있고, 대각선 밖의 모든 항목은 대각선 반대편에 있는 자신의
거울 짝과 자리를 바꾼다.

전치를 손에 넣으면 두 가지 특별한 종류의 행렬에 이름을 붙일 수 있다:

- 어떤 행렬이 자신의 전치와 같을 때, `Mᵀ = M`이면 **대칭(symmetric)**이라 한다.
  구체적으로 모든 거울 짝이 같다: `M[i][j] = M[j][i]`. 대각선을 기준으로 반사해도
  아무것도 바뀌지 않는다.
- 어떤 행렬이 자신의 전치의 *음수*와 같을 때, `Mᵀ = −M`이면 **반대칭
  (antisymmetric)**(또는 *반대칭행렬*)이라 한다. 구체적으로 모든 거울 짝은
  서로 반대되는 숫자로 이루어진다, `M[i][j] = −M[j][i]`. 이 규칙에 의해 강제되는
  결과: 각 대각선 항목은 자기 자신의 음수와 같아야 하는데(`M[i][i] = −M[i][i]`),
  이는 그것이 0일 때만 가능하다 — 그래서 반대칭행렬은 항상 대각선이 모두 0이다.

**분해.** 주장: 임의의 정사각행렬 `M`은 `M = S + A`로 쓸 수 있으며, `S`는
대칭이고 `A`는 반대칭이고, 그런 짝은 정확히 하나뿐이다. 그 구성은

```
S = ½(M + Mᵀ)        A = ½(M − Mᵀ)
```

이다. 여기서 `M + Mᵀ`와 `M − Mᵀ`는 항목별로 만들어지고(대응하는 숫자를 더하거나
빼서), `½(…)`는 모든 항목을 절반으로 만든다. 이것들은 선행 개념인
[[matrix-multiplication]]의 행렬 곱이 아니다; 이는 더 단순한 항목별 합, 차,
스칼라배이며, 행렬 곱 *안에서* 각 칸마다 쓰이는 것과 같은 산술을 여기서는
그 자체로 사용한다.

이것이 성립하는 이유 — 그저 공식이 아니라 *왜*인지. 두 사실이 모든 일을 한다.

*첫째, 두 조각을 더하면 `M`으로 돌아온다.* 항목별로 더하면
`S + A = ½(M + Mᵀ) + ½(M − Mᵀ)`이다. 두 개의 `+½Mᵀ`와 `−½Mᵀ` 항이 서로
상쇄되고, 두 개의 `½M` 항이 합쳐져 온전한 `M`이 된다. 따라서 `S + A = M`이
정확히 성립한다. 아무것도 잃거나 더해지지 않으며, 분해는 그저 같은 숫자들을
재묶음할 뿐이다.

*둘째, 각 조각은 정말로 주장한 종류이다.* 이는 전치에 관한 한 항등식에
기댄다: 합을 대각선을 기준으로 뒤집으면 각 피가산항이 뒤집히므로,
`(M + Mᵀ)ᵀ = Mᵀ + (Mᵀ)ᵀ`이고, 두 번 뒤집으면 원래대로 돌아온다,
`(Mᵀ)ᵀ = M`. 따라서 `(M + Mᵀ)ᵀ = Mᵀ + M = M + Mᵀ`이므로 — `M + Mᵀ`는
전치해도 변하지 않으며, 이것이 `S`를 대칭이게 만든다. 차에 대해서도 같은
단계를 밟으면 `(M − Mᵀ)ᵀ = Mᵀ − M = −(M − Mᵀ)`가 나온다 — 즉 `A`는
자기 자신의 음수로 바뀌므로, 이것이 `A`를 반대칭이게 만든다.

*분해가 유일한 이유.* 공식을 가정하지 않고, `M = S + A`가 **어떤** 대칭
`S`와 반대칭 `A`에 대해 성립한다고 하자. 양변을 전치하면:
`Mᵀ = Sᵀ + Aᵀ = S − A`(`Sᵀ = S`와 `Aᵀ = −A`를 사용). 이제 두 방정식
`M = S + A`와 `Mᵀ = S − A`가 있다. 이들을 더하면 `M + Mᵀ = 2S`, 즉
`S = ½(M + Mᵀ)`이다; 빼면 `M − Mᵀ = 2A`, 즉 `A = ½(M − Mᵀ)`이다. 따라서
*어떤* 유효한 분해든 공식이 만드는 바로 그 하나로 강제된다 — 두 번째 답은
없다. 이 유일성이야말로 우리가 행렬의 *그* 대칭 부분과 *그* 반대칭 부분을
말할 수 있게 해 주는 것이다.

**왜 이것이 중요한가.** 유체가 흐르는 것을 상상하고, 어떤 점 아주 가까이를
살펴보자. 그 점 근처에서 흐름이 위치마다 어떻게 변하는지는 *야코비안*이라
불리는 정사각행렬로 포착된다 — 각 항목은 한 방향으로 한 걸음 움직일 때
속도의 한 성분이 얼마나 빠르게 변하는지를 나타낸다. 그 점에 있는 유체의
작은 덩어리는 이 행렬에 의해 변형되며, 늘어나고 전단되고 회전하는 일이
동시에 일어날 수 있고, 원래의 야코비안은 그 효과들을 뒤엉키게 만든다. 이
분해를 통해 야코비안을 통과시키면 그 엉킴이 갈라진다. 대칭 부분 `S` —
*변형률(strain)*이라 불림 — 은 늘어남과 전단을 모두 담는다: 이것이 작은
유체의 원을 타원으로 변형시키는 것이며, 순 회전은 전혀 없다. 반대칭
부분 `A`는 순수한 *회전*을 담는다: 이는 덩어리를 턴테이블 위의 레코드처럼
모양을 바꾸지 않고 강체로 돌린다. 그래서 하나의 대수적 분해가 두 개의
물리적으로 다른 질문 — "흐름이 어떻게 왜곡되는가?"(`S`를 읽는다)와
"흐름이 어떻게 회전하는가?"(`A`를 읽는다) — 에 답한다. 원래 행렬은 이
둘을 섞어 놓고 있었다.

`A` 안에는 더 날카로운 보상이 숨어 있다. 반대칭행렬은 대각선이 0이고
대각선 아래의 각 항목이 위에 있는 항목의 음수일 뿐이므로, 독립적인 숫자를
매우 적게 가진다 — 2차원에서는 단 하나뿐이다. 그 유일한 독립 숫자가 바로
흐름의 회전율, 즉 **회전(curl)**이라 불리는 양*이다*. 그러므로 반대칭 부분은
그저 "대략적인 회전"에 불과한 것이 아니다 — 그것의 유일한 자유 항목이
곧 회전의 (절반)이다, 정확히. 이 분해는 완전한 도함수 행렬로부터 회전으로
가는 다리이다.

**예시.** 진짜로 한쪽으로 치우친 행렬 — 대칭도 아니고 반대칭도 아니며,
특별한 위치에 0도 없는 — 을 골라서 메커니즘의 모든 부분이 실제로
작동하게 하자:

```
M = [ 2  3 ]
    [ 1  4 ]
```

먼저 전치: 각 대각선 밖 항목을 그 거울 짝과 바꾸고, 대각선의 `2`와 `4`는
그대로 둔다. 대각선 밖의 `3`(행 1, 열 2)과 `1`(행 2, 열 1)이 자리를 바꾼다:

```
Mᵀ = [ 2  1 ]
     [ 3  4 ]
```

이제 `S = ½(M + Mᵀ)`이다. 항목별로 더하면: `2+2=4`, `3+1=4`, `1+3=4`,
`4+4=8`; 그다음 각각을 절반으로 하면:

```
S = ½ [ 4  4 ]  =  [ 2  2 ]
      [ 4  8 ]     [ 2  4 ]
```

`S`가 대칭인지 확인하자: 거울 짝은 `2`와 `2` — 같으므로 `Sᵀ = S`이다. 좋다.

이제 `A = ½(M − Mᵀ)`이다. 항목별로 빼면: `2−2=0`, `3−1=2`, `1−3=−2`,
`4−4=0`; 그다음 각각을 절반으로 하면:

```
A = ½ [ 0   2 ]  =  [ 0   1 ]
      [ −2  0 ]     [ −1  0 ]
```

`A`가 반대칭인지 확인하자: 대각선이 모두 0이고, 거울 짝은 `1`과 `−1` —
서로 반대이므로 `Aᵀ = −A`이다. 좋다.

마지막으로 이들을 다시 합쳐서 확인하자: `S + A`를 항목별로 계산하면
`2+0=2`, `2+1=3`, `2+(−1)=1`, `4+0=4`이며, 이는 정확히 원래의
`M = [[2,3],[1,4]]`이다. 분해에서 아무것도 잃지 않았다.

이 예시에서 물리를 읽어 보면: 변형률 `S = [[2,2],[2,4]]`는 흐름이 덩어리를
늘이고 전단한다는 것을 말한다(대각선 밖의 `2`들은 전단이고, 대각선의
`2`와 `4`는 두 축을 따른 늘어남이다). 회전 `A = [[0,1],[−1,0]]`은 독립적인
숫자 `1`을 하나 가진다; 그 항목은 회전의 절반이므로, 이 흐름은 변형되는
동시에 명확하고 단일한 속도로 회전한다. 하나의 행렬, 두 개의 깔끔한
이야기.
