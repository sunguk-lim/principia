# 텔레메트리 문맥

## 요약

**텔레메트리 문맥(telemetry context)**은 현재 실행 중인 작업에 연결된 작은 상관관계
데이터 묶음이다. 개념적으로는 불변 [[key-value]] 매핑이다. 키는 트레이스 ID, 스팬 ID,
배기지 항목 같은 필드를 식별하고 값은 해당 식별자나 메타데이터를 담는다.

## 상세 설명

문맥은 소유권 문제를 푼다. 한 프로세스 안에서 많은 요청이 동시에 실행될 수 있으므로
계측 코드가 “현재 트레이스 ID”를 일반 전역 변수 하나에 저장할 수 없다. 대신 각 실행
단위가 자기 현재 문맥을 본다. 자식 작업을 시작할 때 부모 매핑을 바꾸지 않고 새 매핑을
파생하므로, 중첩 작업이 끝나면 이전 문맥을 복원할 수 있다.

예를 들어 결제 핸들러가 `{trace_id: "7fa1", span_id: "a10c"}`로 시작한다고 하자.
데이터베이스 작업을 시작하면 `{trace_id: "7fa1", span_id: "b205"}`를 파생한다.
두 작업이 한 요청에 속하므로 트레이스 ID는 유지되고, 데이터베이스 호출은 별도 작업이므로
스팬 ID는 바뀐다. 호출이 끝나면 핸들러는 첫 매핑을 복원한다.

매핑은 `tenant=shop-42` 같은 애플리케이션 정의 배기지(baggage) 쌍도 담을 수 있다.
하지만 임의의 배기지는 신뢰 경계를 넘을 수 있으므로 주의해야 한다. 문맥은 프로세스
내부 표현이고, 선택한 필드를 다른 프로세스로 옮기는 일은 문맥 전파의 별도 책임이다.
