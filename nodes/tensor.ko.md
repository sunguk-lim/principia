# 텐서 (Tensor)

## 요약

**텐서(tensor)**는 값이 직사각형 형태로 배열된 다차원 모음이다. **형상(shape)**은
각 축의 길이를 나타내고, 하나의 공통 원소 형식은 모든 값의 인코딩 방식을 나타낸다.
스칼라는 축이 0개, 벡터는 1개, 행렬은 2개이며 텐서는 임의 개수의 축을 가질 수 있다.

## 상세 설명

[[dynamic-array]]는 텐서를 이해하는 데 필요한 두 요소, 즉 순서가 있는 저장과 정수
인덱싱을 제공한다. 텐서는 이 아이디어를 여러 축으로 확장하면서 직사각형 형상을
요구한다. 예를 들어 형상 `[2, 3]`은 원소가 3개인 행이 2개라는 뜻이다. 인덱스
`[1, 2]`는 두 번째 행의 세 번째 열을 고른다. 전체 원소 수는 축 길이의 곱이므로
`[2, 3]`에는 `2 × 3 = 6`개의 값이 들어간다.

또 다른 요소는 [[numeric-precision-formats]]에서 정한 하나의 원소 형식이다.
`float32[2,3]`으로 선언한 텐서는 같은 32비트 부동소수점 형식으로 인코딩된 값 6개를
담는다. 형상과 원소 형식은 서로 다르다. `float32[2,3]`과 `int8[2,3]`은 위치는
같지만 값을 다르게 인코딩하고, `float32[3,2]`는 값의 개수는 같지만 축 배치가 다르다.

**구체적인 예.** 값 `[1, 2, 3, 4, 5, 6]`, 형상 `[2, 3]`, 원소 형식
`float32`를 사용하자. 마지막 축을 기준으로 평평한 값을 나누면 행
`[1, 2, 3]`과 `[4, 5, 6]`이 된다. 따라서 인덱스 `[0, 1]`은 `2`, 인덱스
`[1, 2]`는 `6`이다. 소비자는 바이트를 모호함 없이 해석하려면 값, 형상, 원소 형식
세 가지가 모두 필요하다.
