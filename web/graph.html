🔄 The lifecycle — a concept enters, the graph settles

It starts with a prompt. The graph's one entry point is a plain-language request ("explain X") — everything below is the agent + brain.py turning that single ask into nodes & edges. An agentic graph database: each row is a CRUD tool-call — command(typed args) → result (∅ = a mutation returns nothing) — issued by a subject. Loop: the LLM turns a prompt into a tool-call → brain.py runs it on the graph → git versions. C create · R read · U update · D delete. Compose the whole sub-graph first, then scaffold + sync per node; ground-check & lock are the rare settle-loop. ▸ rows unfold.

🌱 How the graph grows

A concept enters as a root; its prerequisites grow beneath it. A second concept grows its own tree — but one of its prerequisites is a node that already exists, so it links to it instead of duplicating (the gold shared node). That reuse is the closed-world graph.
